# PV Fault Diagnosis Dataset

## Overview
This directory contains the machine-readable synthetic dataset generated by the deterministic digital twin PV model, identical to the firmware running on the ESP32-S3.

## Dataset File: `pv_dataset.csv`
- **Rows**: 1,000 observations (250 samples per class).
- **Target Variable**: `fault_mode` (4 classes).
- **Data Source**: ESP32-S3 Serial telemetry stream or `python/generate_dataset.py`.

## Feature Descriptions

| Column | Unit | Range | Description |
| :--- | :--- | :--- | :--- |
| `timestamp_ms` | ms | $\ge 0$ | Telemetry sample timestamp from microcontroller boot |
| `irradiance_wm2` | $\text{W/m}^2$ | $0 - 1000$ | Solar irradiance (represented by Potentiometer on GPIO 1) |
| `humidity_percent` | $\%$ | $0 - 100$ | Environmental relative humidity from DHT22 (GPIO 4) |
| `ambient_temp_c` | $^\circ\text{C}$ | $-20 - 80$ | Ambient temperature from DHT22 (GPIO 4) |
| `pv_temp_c` | $^\circ\text{C}$ | $15 - 85$ | Estimated PV module temperature including solar heating |
| `voltage_v` | $\text{V}$ | $0 - 25$ | PV terminal voltage with negative temperature coefficient |
| `current_a` | $\text{A}$ | $0 - 3.5$ | PV array output current proportional to irradiance |
| `power_w` | $\text{W}$ | $0 - 65$ | Generated electrical power ($P = V \times I$) |
| `fault_mode` | Categorical | 4 values | Ground truth label: `NORMAL`, `PARTIAL SHADE`, `OPEN CIRCUIT`, `OVER TEMP` |

## Class Characteristics
1. **NORMAL**: Nominal voltage ($16 - 19\text{ V}$), current proportional to irradiance ($0.4 - 2.7\text{ A}$), cell temp slightly above ambient.
2. **PARTIAL SHADE**: Current reduced by $55\%$ ($\text{shading\_factor} = 0.45$), voltage remains high ($\approx 95\%$), power substantially degraded.
3. **OPEN CIRCUIT**: Current drops to $0.00\text{ A}$, voltage sits near open-circuit $V_{oc}$ ($20 - 22\text{ V}$), power is $0.00\text{ W}$.
4. **OVER TEMP**: Cell temperature elevated by $+35^\circ\text{C}$ ($> 60^\circ\text{C}$), voltage severely drops ($\approx 12 - 14\text{ V}$), current remains high.
